# MotecLogGenerator

Utility for generating MoTeC `.ld` files that can be analyzed with [MoTeC i2 Pro](https://www.motec.com.au/i2/i2overview/) from external telemetry log sources. Generated log files are "Pro Enabled", so they can be opened in either *i2 Standard* or *i2 Pro*.

Currently the following input types are supported:
* **RaceChrono Native `.rcz` Archives** (Direct binary unzipping, multi-stint auto-splitting & high-precision 20Hz/25Hz GPS)
* **AiM Solo / RaceStudio CSV files** (Auto-maps `PPS`, `SteerAngle`, `BrakePress`, `RPM`, `Gear`, temperatures, and parses `Beacon Markers` lap beacons)
* **RaceChrono CSV files**
* **Raw CAN bus logs** (paired with a `.dbc` file)
* **COBB Accessport CSV logs**
* **Generic CSV files**

### Sim & Overlay Compatibility
Log files generated by this tool (including high-precision GPS coordinates, lap beacons, and physical math channels) are fully compatible and coordinate-aligned with telemetry exported from [ACTI (Assetto Corsa Telemetry Interface)](https://www.overtake.gg/downloads/acti-assetto-corsa-telemetry-interface.3948/). You can open real-world track day logs alongside ACTI simulator logs in MoTeC i2 Pro for side-by-side overlay comparison.

## Python Version & Dependencies

* **Python Version**: Python 3.8 or higher (3.8 ~ 3.12+)
* **Dependencies**: `numpy` (required), `cantools` (only for CAN log type)

Install dependencies via pip:
```bash
pip install numpy
pip install cantools  # only needed for CAN bus log processing
```

## Usage Examples

### 1. RaceChrono `.rcz` Native Archives (Recommended)
```bash
# Convert RaceChrono native .rcz archive directly
python motec_log_generator.py /path/to/session.rcz RCZ
```
*Auto-detects multi-stint sessions (multiple resumes during a track day) and exports separate `.ld` and `.ldx` files for each stint.*

### 2. AiM Solo & RaceChrono CSV Logs
```bash
# Convert AiM Solo or RaceChrono CSV log
python motec_log_generator.py /path/to/aim_or_racechrono.csv RACECHRONO
```
*Automatically maps channels like `PPS` (Throttle), `SteerAngle`, `BrakePress`, `OilTemp`, `ECT` with SI unit conversions (`psi -> kPa`, `°F -> °C`, `mph -> km/h`), and extracts lap beacon timestamps.*

### 3. CAN Bus Logs
```bash
python motec_log_generator.py /path/to/can_data.log CAN --dbc /path/to/car.dbc
```

### 4. COBB Accessport & Generic CSV Logs
```bash
python motec_log_generator.py /path/to/accessport.csv ACCESSPORT
python motec_log_generator.py /path/to/data.csv CSV
```

## Command Line Options

```
usage: motec_log_generator.py [-h] [--output OUTPUT] [--frequency FREQUENCY]
                              [--min_lap_sec MIN_LAP_SEC] [--lap LAP] [--stint STINT]
                              [--driver DRIVER] [--vehicle_id VEHICLE_ID]
                              [--venue_name VENUE_NAME] [--event_name EVENT_NAME]
                              log {CAN,CSV,ACCESSPORT,RACECHRONO,RCZ}

Options:
  --output OUTPUT          Path for output .ld file (default: same directory as input log)
  --frequency FREQUENCY    Fixed frequency to resample all channels at or 'auto' (default: auto)
  --gpx                    Generate GPX track file (default: false)
  --kml                    Generate KML Google Earth track file (default: false)
  --min_lap_sec MIN_LAP    Minimum valid lap duration in seconds to filter noise (default: 15.0s)
  --lap LAP                Specific lap number to export (e.g. 1, 15) or 'all' (default: all)
  --stint STINT            Specific RCZ stint to export or 'all' for auto-split (default: all)
  --driver DRIVER          Driver name metadata (auto-extracted from log if omitted)
  --vehicle_id VEHICLE_ID  Vehicle model metadata (auto-extracted from log if omitted)
  --venue_name VENUE_NAME  Track venue metadata (auto-extracted from log if omitted)
```

## Log Verification Tool (`verify_log.py`)

A built-in verification utility is provided to validate generated `.ld` and `.ldx` files prior to opening in MoTeC i2.

```bash
# Verify a generated MoTeC .ld file
python verify_log.py /path/to/generated_log.ld
```

### What `verify_log.py` Validates:
1. **Binary Header Integrity**: Unpacks MoTeC `.ld` binary headers and checks driver, vehicle, track venue, and datetime metadata.
2. **Channel Data & Value Bounds**: Verifies that channels have valid sample counts, zero `NaN`/`Inf` anomalies, and realistic physical ranges (e.g., GPS Latitude in [-90, 90], Longitude in [-180, 180]).
3. **Advanced Math Channels**: Confirms the presence of pre-calculated vehicle dynamics channels (`Tire Slip Angle FL/FR/RL/RR`, `Understeer Index`, `G Force Combined`).
4. **XML Beacon Alignment (`.ldx`)**: Parses accompanying `.ldx` files to verify non-monotonic lap beacon timestamp sorting, fastest lap times, and total lap counts.

## Running Tests

```bash

python tests/test_examples.py

pip install pytest
```
